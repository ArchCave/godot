## 3. 크게 바뀐 스크립트

### 3.1 `Scripts/player.gd` (+111 lines, 가장 중요)

- **`_apply_character_data()` 신설**: `_ready()`에서 `PlayerStats.get_selected()`를 받아 자기 자신의 `sprite.texture / hframes / vframes / offset`, `anim`의 빈 라이브러리(`""`)를 통째로 교체, `move_speed / air_speed_multiplier / jump_force / health / climb_speed / attack_scene / skill_scene`을 덮어씀.
- **빈 라이브러리 교체 이디엄**: `anim.remove_animation_library("")` 후 `anim.add_animation_library("", character_data.animation_library)`. `""` 라이브러리는 "Idle", "Walk", "Jump", "Death" 4개 클립을 반드시 포함해야 함(스크립트가 이 이름으로 호출).
- **사다리 시스템**: `ladder_tilemap : TileMapLayer` export. `_is_on_ladder()`은 플레이어 global → TileMap local → 좌표 변환 후 `get_cell_tile_data().get_custom_data("is_ladder")`로 판정. 진입 트리거 = "위/아래 입력" 또는 "사다리 위에서 떨어지는 중". `ui_jump`로 사다리에서 점프 탈출.
- **점프 감각 개선**: `coyote_time` (바닥 떠난 후 0.08s 점프 유예), `jump_buffer_time` (착지 직전 0.1s 점프 입력 버퍼링), `air_speed_multiplier` (공중 수평 가속 배수).
- **애니메이션 오프셋 시스템**: `Idle`/`Walk` 마다 `sprite_offset + character_data.idle_offset_delta / walk_offset_delta`로 미세 위치 보정.
- **`Ladder` 애니메이션이 있으면 climb 중 그걸 사용 + 정지 시 `speed_scale = 0`** 으로 같은 프레임 고정. 없는 캐릭터는 폴백.
- **그룹 자동 등록**: `if not is_in_group("Player"): add_to_group("Player")` — `PlayerSpawner`로 동적 스폰될 때도 적이 항상 플레이어를 찾을 수 있게.
- **`ladder_tilemap` 그룹 폴백**: `null`이면 "Ladders" 그룹 첫 노드를 자동 탐색.

## 5. 디자인 결정의 핵심 (아키텍처 관점)

### 5.1 "한 씬, 다 캐릭터" 원칙
모든 캐릭터가 같은 `Player.tscn`을 공유한다. 이유:
- 레벨 씬에 들어있는 Player 인스턴스 1개를 캐릭터마다 갈아끼우지 않아도 된다.
- 카메라/콜리전/노드 구조가 똑같으므로 적/플랫폼이 "어떤 캐릭터인가" 신경 안 쓰고 `is_in_group("Player")`만 본다.
- 캐릭터 수가 늘어도 메모리/씬 그래프가 폭발하지 않는다.

### 5.2 "데이터가 비주얼을 결정" 원칙
`Player.tscn._ready()`에서 `CharacterData`가 `sprite.texture`, `anim`의 `""` 라이브러리, `move_speed` 등을 자기 자신에 적용한다. 이는 **Resource = 데이터, Scene = 구조**라는 Godot의 모범 분리 패턴이다.

### 5.3 "Opt-in 게이팅" 원칙
캐릭터별 반응이 필요한 곳은 모두 `allowed_character_id: StringName = &""` 또는 `enemy_to: StringName = &""` 같은 export 필드를 받고, 빈 값이면 **모든 캐릭터에 동작**하도록 폴백한다. 즉:
- 신규 노드는 별도 설정 없이 기존(=모든 캐릭터) 동작.
- 캐릭터 한정이 필요하면 인스펙터에서 한 줄 입력.
- 레거시 코드가 깨지지 않는다.

### 5.4 "다중 폴백" 원칙
거의 모든 진입점에 폴백이 2~3단 쌓여 있다:
- `PlayerStats.get_selected()`: 선택 id → 기본 id → 배열 첫 항목.
- `player.ladder_tilemap`: 인스펙터 → "Ladders" 그룹.
- `smooth_camera._target`: 부모 CharacterBody2D → "Player" 그룹.
- `jump_platform._player`: 인스펙터 NodePath → "Player" 그룹 → 매 프레임 재시도.
- `player_spawner.scene_to_spawn`: `PlayerStats.get_selected_scene()` → `fallback_scene` export.

이는 **씬 인스턴스화 순서가 비결정적인** Godot에서 신호/_ready() 타이밍 문제를 회피하기 위함이다.

### 5.5 "비파괴 비활성화" vs "파괴"
- `EndFlag`: 비매칭 캐릭터 시 **비파괴** (visible=false + monitoring OFF). 같은 위치에 캐릭터별로 3개 깔아두는 패턴.
- `PlayerSpawner`: 비매칭 캐릭터 시 **파괴** (`queue_free`). 트리에 잔류할 필요가 없는 마커니까.
- `conditional_through`: 조건 충족 시 **자기 자신 파괴**. 영구적인 길 개방을 위함.

1. **`Scenes/characters/PlayerPlanner.tscn` / `PlayerResearcher.tscn`** — 만들어졌지만 `bird.tres / planner.tres / researcher.tres`의 `scene` 필드가 비어있으면 사용되지 않는다. 의도적으로 비워뒀다면 OK, 깜빡 잊은 거라면 `PlayerStats.get_selected_scene()`를 호출하는 곳(현재는 `PlayerSpawner`뿐)이 자동 활용한다.

3. **루트의 untracked 이미지/PDF/메모** — `git status` 정리 필요(위 4.5 참조).
4. **`planner.tscn`에 `Ladder` 애니메이션이 없는 경우** — `player.gd`가 `anim.has_animation("Ladder")`로 가드하므로 깨지진 않지만, planner가 사다리 맵을 지나면 Walk/Idle 폴백 애니메이션이 재생됨. researcher는 ladder 폴더 전용 스프라이트가 있음(`Sprite/researcher/ladder/`).
